# Ishita Agrawal — Portfolio

A responsive, dark-first portfolio built with Next.js, TypeScript, Tailwind CSS, and Lucide icons. Content and public links are centralized in `src/data/portfolio.ts`.

## Requirements

- Node.js 20 or later
- npm

## Run locally

```powershell
npm install
npm run dev
```

## Checks and production build

```powershell
npm run typecheck
npm run lint
npm run build
npm start
```

## Updating portfolio content

Edit `src/data/portfolio.ts` to update:

- Profile details and social links
- Navigation, projects, categories, and case-study content
- Experience, skills, achievements, certificates, and research

The project's claims are intentionally limited to what was supplied or visible in the linked repositories. The research page does not publish metrics because evaluation-result artifacts were not found.
